This link never changes. Every time you open it, you get the newest build.

## How to play
1. Unzip `SheepySheep.zip`.
2. Open Steam.
3. Run `SuruBasinda.exe`.
4. Host a game or join a friend. On the same network, LAN also works.

The version and date are in `surum.txt`. Older builds: [Releases](https://github.com/harun0y/SheepySheep-builds/releases).
